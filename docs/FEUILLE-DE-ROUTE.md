## Les décisions qui t'attendent (❓)

1. ✅ (22.10 : la clé sur le labo, docs/PUSH.md) **Les notifications push (APNs)** : il faut une clé APNs (developer.apple.com › Keys › + › Apple Push Notifications service). Le serveur qui envoie (le labo) doit la détenir, alors que la règle actuelle dit « les secrets Apple jamais sur le Boxion ». Options : (a) la clé APNs sur le labo, isolée et révocable (elle ne sert QU'À envoyer des notifications, pas à publier l'app) ; (b) un petit relais ailleurs ; (c) pas de push, seulement app ouverte.
2. **Sign in with Apple** : la route labo qui crée un compte **bion** à partir du jeton Apple. À confirmer : l'e-mail masqué d'Apple suffit, pas d'autre donnée.
3. **Testeurs externes** (Nexus des xeroctions) : chaque version passe par une revue bêta d'Apple (≈ 1 jour). On y va maintenant ou on garde des testeurs internes ?
4. **Steam Workshop** : quand le jeu pourriture-4 existe sur Steam (la clé API vivra sur le boxion).
